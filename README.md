# Rentalo website

Simple informational site for Rentalo: car hire in Melbourne, e-bike hire in Melbourne and Adelaide.

- `index.html`: cars page
- `ebikes.html`: e-bikes page
- `styles.css`, `app.js`: shared styles and the image carousel / WhatsApp links

Published with GitHub Pages from the `main` branch: https://neozs.github.io/rentalo-website/
